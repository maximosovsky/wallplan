# WallPlan — تقويم أعمال دبي والإمارات

**خطط لعقود على الحائط**

[![عرض حي](https://img.shields.io/badge/demo-osovsky.com/wallplan/ar-81D8D0?style=for-the-badge)](https://osovsky.com/wallplan/ar/)
[![الرخصة: CC BY-SA 4.0](https://img.shields.io/badge/License-CC_BY--SA_4.0-lightgrey?style=for-the-badge)](https://creativecommons.org/licenses/by-sa/4.0/)

مولد تقويم حائط متعدد السنوات مع مخططات غانت وقوائم أيام وأشهر مصغرة. اختر المدة والورق، صدّر SVG أو PDF.

**بدون تبعيات · بدون تسجيل · 100% خصوصية**

## ✨ الميزات

| الميزة | الوصف |
|--------|-------|
| **SVG** | عرض SVG خالص — عمودي، غانت، شهر مصغر |
| **المدة** | من شهر إلى 20 سنة |
| **الورق** | A4، A3، لفة 914 ملم (فردي/مزدوج/رباعي) |
| **التصدير** | PDF/SVG مع خطوط IBM Plex Sans + Noto Sans Arabic |
| **عطل الإمارات** | رمضان، عيد الفطر، عيد الأضحى، اليوم الوطني |
| **أشهر هجرية** | خوارزمية 2025-2034، حدود محرم |
| **تبديل اللغة** | ع / RU / EN |
| **طبقة العطل** | عطل روسية وأمريكية للمقارنة |
| **إبراز العطل** | خلفية وردية، 3 مستويات |
| **ألوان الأشهر** | لوحة Material Design |
| **إدخالات مخصصة** | زر W لإضافة ملاحظات |
| **الهاتف** | سحب وتكبير، شريط أدوات سفلي |
| **بدون اتصال** | PWA مع Service Worker |
