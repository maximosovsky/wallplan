# WallPlan — Product Hunt Launch Draft

## Listing

**Name:** WallPlan

**Tagline (60 chars max):**
Multi-year wall calendar generator — SVG & PDF, zero dependencies

**Description:**
Generate printable wall calendars from 1 month to 20 years. Gantt rows for project planning, month color palette, custom date entries, and hide-days timeline mode. Export to SVG or PDF for any paper size — A4, A3, or 914mm engineering rolls.

Built with vanilla JS, zero dependencies, fully open-source.

**Topics:** Productivity, Design Tools, Open Source, Developer Tools

**Website:** https://osovsky.com/wallplan

**Gallery (4 screenshots needed):**
1. Full calendar view — 2-year calendar with Gantt rows and month colors
2. Mobile view — bottom sheet with settings on phone
3. PDF export — printed calendar on wall (photo or mockup)
4. Miro integration — calendar generated inside Miro board

## Maker Comment (first comment after launch)

Hey PH! I'm Max, and I built WallPlan because I needed a way to see my projects across multiple years on one wall.

Existing tools either:
- Only do 1 year (Calidar, Kruglendar)
- Require InDesign (Calidar)
- Are digital-only (Notion planners)

WallPlan is different:
- **Up to 20 years** on a single timeline
- **Gantt rows** for project milestones (no other calendar generator has this)
- **914mm roll paper** support for engineering plotters
- **Zero dependencies** — runs entirely in the browser
- **Miro integration** — native app + Miroverse template for team planning

It's free, open-source (CC BY-SA 4.0), and works offline.

I'd love your feedback — what features would make this more useful for your workflow?
