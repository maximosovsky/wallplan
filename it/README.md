# WallPlan — Calendario Italia & Venezia

**Pianifica decenni sulla parete**

[![Demo](https://img.shields.io/badge/demo-osovsky.com/wallplan/it-81D8D0?style=for-the-badge)](https://osovsky.com/wallplan/it/)
[![Licenza: CC BY-SA 4.0](https://img.shields.io/badge/License-CC_BY--SA_4.0-lightgrey?style=for-the-badge)](https://creativecommons.org/licenses/by-sa/4.0/)

Generatore di calendari pluriennali con diagrammi di Gantt, liste giorni e mini-mesi. Configura durata, formato carta, esporta in SVG o PDF.

**Zero dipendenze · Senza registrazione · 100% privato**

## ✨ Funzionalità

| Funzione | Descrizione |
|----------|-------------|
| **SVG** | Rendering SVG puro — Verticale, Gantt, Mini-mese |
| **Durata** | Da 1 mese a 20 anni |
| **Carta** | A4, A3, rotolo 914 mm (singolo/doppio/quadruplo) |
| **Esportazione** | PDF/SVG con font IBM Plex Sans integrati |
| **Festività nazionali** | Capodanno, Epifania, Pasquetta, 25 Aprile, Ferragosto, Natale |
| **Festività veneziane** | Carnevale, Sensa, Redentore, Regata Storica, Salute |
| **Cambio lingua** | IT / RU / EN |
| **Overlay festività** | Festività russe e americane per confronto |
| **Weekend** | Sfondo rosa, 3 livelli |
| **Colori mensili** | Palette Material Design |
| **Voci personalizzate** | Pulsante W per annotazioni |
| **Mobile** | Scorrimento e zoom, barra strumenti inferiore |
| **Offline** | PWA con Service Worker |
