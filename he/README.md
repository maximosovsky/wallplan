# WallPlan — לוח שנה עסקי לישראל

**תכנן עשורים על הקיר**

[![הדגמה](https://img.shields.io/badge/demo-osovsky.com/wallplan/he-81D8D0?style=for-the-badge)](https://osovsky.com/wallplan/he/)
[![רישיון: CC BY-SA 4.0](https://img.shields.io/badge/License-CC_BY--SA_4.0-lightgrey?style=for-the-badge)](https://creativecommons.org/licenses/by-sa/4.0/)

מחולל לוח שנה רב-שנתי עם תרשימי גנט, רשימות ימים ולוחות מיני-חודשים. הגדר משך, בחר גודל נייר, ייצא ל-SVG או PDF.

**אפס תלויות · ללא הרשמה · 100% פרטי**

## ✨ תכונות

| תכונה | תיאור |
|--------|--------|
| **SVG** | עיבוד SVG טהור — אנכי, גנט, מיני-חודש |
| **משך** | מ-1 חודש עד 20 שנה |
| **נייר** | A4, A3, גליל 914 מ"מ (יחיד/כפול/מרובע) |
| **ייצוא** | PDF/SVG עם גופני IBM Plex Sans + Noto Sans Hebrew |
| **חגי ישראל** | ראש השנה, יום כיפור, סוכות, חנוכה, פורים, פסח, שבועות |
| **חודשים עבריים** | אלגוריתמיים 2024-2045, גבול תשרי |
| **מיתוג שפות** | עב / RU / EN |
| **שכבת חגים** | חגים רוסיים ואמריקאיים להשוואה |
| **הדגשת סופי שבוע** | רקע ורוד, 3 רמות |
| **צבעי חודשים** | פלטת Material Design |
| **רשומות מותאמות** | כפתור W להוספת הערות |
| **מובייל** | גלילה וזום, סרגל כלים תחתון |
| **לא מקוון** | PWA עם Service Worker |
