# WallPlan — 中国商务日历

**把未来十年挂在墙上**

[![在线演示](https://img.shields.io/badge/demo-osovsky.com/wallplan/zh-81D8D0?style=for-the-badge)](https://osovsky.com/wallplan/zh/)
[![许可: CC BY-SA 4.0](https://img.shields.io/badge/License-CC_BY--SA_4.0-lightgrey?style=for-the-badge)](https://creativecommons.org/licenses/by-sa/4.0/)

多年挂历生成器，带甘特图、每日列表和迷你月历。配置时长，选择纸张，导出 SVG 或 PDF，打印到工程纸上。

**零依赖 · 无需登录 · 100% 隐私**

## ✨ 功能

| 功能 | 说明 |
|------|------|
| **SVG 渲染** | 纯 SVG — 垂直列表、甘特图、迷你月历 |
| **时长** | 1 个月到 20 年 |
| **纸张** | A4、A3、914mm 工程卷纸（单/双/四份） |
| **PDF/SVG 导出** | 内嵌 IBM Plex Sans + Noto Sans SC 字体 |
| **中国节假日** | 春节、清明、劳动节、端午、中秋、国庆 |
| **补班调休** | 国务院公布的补班安排，不计入高亮 |
| **中国生肖** | 动物 + 五行标签（如 🐴 火马） |
| **三语切换** | EN / RU / 中文 |
| **假日叠加** | 俄中假日灰色对比 |
| **周末高亮** | 粉色背景，3个级别 |
| **月份色彩** | 温度色彩调色板（Material Design） |
| **自定义条目** | W 按钮添加日期标注 |
| **移动端** | 触摸平移缩放，底部工具栏 |
| **离线** | Service Worker PWA 支持 |
